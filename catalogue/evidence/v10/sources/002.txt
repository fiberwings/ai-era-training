What you'll learn
Build on-device memory systems that store, retrieve, filter, and forget experiences locally using vector search.
Create a multimodal, offline assistant that can recall information from text notes, voice recordings, and images.
Teach the assistant to recognize something new from a few photos, without retraining a model.
About this course
Introducing “Building AI Assistants with On-Device Memory,” built in partnership with Qdrant and taught by Dylan Couzon, Developer Experience Engineer at Qdrant.
A cloud-based assistant can remember what it sees, hears, and is told, but only by staying connected and sending that data to a remote server. An assistant that runs on the device builds that memory locally instead. Every note, photo, or recording becomes a vector you can search by meaning, tag with context, and delete on command, all without leaving the device.
Keeping memory on the device lets it work without depending on a network connection. You’ll build this memory system yourself, filter and delete memories on demand, then extend it to voice and images so it can answer questions about your day and learn to recognize objects from a handful of examples. The same approach runs on any device, including a Mac or Windows PC, with no specialized hardware required.
In detail, you'll:
Learn how on-device memory flow works from capturing, to storing, recalling, and forgetting experiences using local vector memory.
Learn how the hardware architecture of the on-device assistant works, and how the same assistant can run on different devices.
Build a local memory system that stores, retrieves, filters, and forgets text and image memories.
Build an offline assistant that stores and recalls experiences across text, voice, and images.
Teach an AI application to recognize new objects from stored examples and calibrate a similarity threshold for recognition.
Learn how you can run the on-device AI assistant on a local machine, including Mac, Windows, and Linux.
By the end, you’ll know how to give a device a memory of its own experiences, one you can extend in the field by adding examples instead of retraining a model.
Who should join?
Anyone building AI applications who wants them to work offline and keep user data on the device. Familiarity with Python is recommended to make the most of the hands-on labs.
