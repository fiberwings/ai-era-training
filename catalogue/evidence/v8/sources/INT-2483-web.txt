L111: ### Penetration Testing 5 lectures • 14min
L112: 
L113:   * What is Penetration Testing?2:19
L114: 
L115: Penetration testing is a simulated cyber attack to identify vulnerabilities before real attackers exploit them, using techniques such as the Mitre attack and the Mitre Atlas framework.
L116: 
L117:   * Penetration Testing in Cyber Security 2:33
L118: Penetration testing detects security weaknesses, informs risk management with real-world vulnerability data, validates controls, and guides proactive security improvements through remediation insights and resilience building.
L119: 
L120:   * Red Teaming vs. Penetration Testing 4:23
L121: 
L122: Red teaming provides an end-to-end security assessment using adversary-like ttps, while penetration testing targets specific vulnerabilities within a defined, time-bound scope.
L123: 
L124:   * The Importance of Penetration Testing for GenAI 1:22
L125: Perform penetration testing for gen ai platforms to uncover vulnerabilities that enable model inversion and data exfiltration, assess privacy compliance, and prevent unauthorized access to sensitive data.
L126: 
L127:   * Threat Vectors for GenAI 3:48
L128: 
L129: Identify prominent threat vectors for genai applications, including prompt injection, data leakage, overreliance, data poisoning, supply chain risks, insecure plugins, jailbreaks, and model vulnerabilities across data, usage, application, and platform.

L131:

L142:

L144: Conduct API endpoint scanning and input analysis to map data flows and enumerate backend services and dependencies in the LLM, then perform a configuration review to identify vulnerabilities and misconfigurations.
L145:

L270:   * Sensitive Information Disclosure 3:00
L271:

L299: 
L300: Unbound consumption causes excessive inferences that deplete resources, degrade performance, and can trigger denial of service, wallet exhaustion, or costly model extraction in cloud LLM deployments.
