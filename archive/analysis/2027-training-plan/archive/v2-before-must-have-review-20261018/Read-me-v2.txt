2027 Cyber Workforce Training Plan — Version 2
Prepared 18 October 2026 against catalogue v10 and capability model 2.

Open 2027-Training-Plan-v2.html in a current desktop browser. The report is self-contained; its evidence explorer and embedded downloads work without companion files. External course links require internet access. No learner data or organisation-wide headcount is embedded.

2027-recommended-v2.json is the curated annual recommendation and distributed Training Planner default. Import it into the current Training Planner to edit the proposal. The coding and coached scenarios are audience adaptations. The coverage benchmark is a diagnostic comparison, not a delivery recommendation.

Seven CSV files provide time, course selections, need scores, requirement evidence/gaps, internal commitments, development briefs and the 140-outcome capability crosswalk. Internal learning is proposed and earns no scored coverage. The results/configuration files retain detailed calculation inputs and outputs; verification-v2.json records reconciliation.

The code files are audit/rebuild sources for the ai-era-training project. They require that project's catalogue and planner modules, and the locally installed HiGHS solver; the ZIP alone is not a standalone development environment. From the project root: run node analysis/2027-training-plan/build_plan.mjs --publish, python3 analysis/2027-training-plan/build_report.py, then python3 training-planner/scripts/build_standalone.py. Publishing replaces the distributed default, never browser-local plans.

The previous report and plan are preserved in the project under analysis/2027-training-plan/archive/v1-before-model-v2-20261018/. Their hash manifest is included for traceability; old artifacts are not bundled into this new delivery pack. Source workbook assessments remain unchanged.
