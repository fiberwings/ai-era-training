# Capability framework

The [Agentic-Era Workforce Capability Model](Agentic-Era_Workforce_Capability_Model.md) is the authoritative description of the framework: Foundation + agentic level + relevant role specialisms + tool training. Current version: **2, revision 3**.

The [CSV crosswalk](Capability_Model_Crosswalk.csv) and [app JSON crosswalk](../training-planner/public/data/capability-crosswalk.json) map 140 active outcomes to the 23 existing scoring groups. [Prior model documents](../archive/capability-framework/) remain unchanged for traceability.

The readable model and crosswalks are generated by `training-planner/scripts/build_capability_model.mjs`, using the imported catalogue and the planner's `capability-model.js`, `model-explanation.js` and `presentation.js` modules. The source modules implement applicability, role mappings and presentation; the document expresses the agreed framework. Reconcile discrepancies before rebuilding and preserve approved prose.

From the project root:

```sh
node training-planner/scripts/build_capability_model.mjs
```

After an intentional model change, verify both apps, rebuild their distributions, and review the [presentations](../presentations/README.md). Do not change rubric evidence or weighting merely to simplify the explanation.
